Trusting keys

  • Create your key pair:
    • gpg –gen-key
  • Give your "public key" to a friend
    • gpg –fingerprint
  • Recieve your friend "public key"
    • gpg –recv-keys
    • verify fingerprint and owner identify,
    • NEVER blindly trust without verification
  • Trust your friend's key: gpg –sign-key "$KEY"

Using keys:

  • Encode a file for a friend
    • gpg –encrypt –output "$file.gpg" –recipient "$EMAIL" "$file"
  • Decode a file fron your friend
    • gpg –decrypt –output "$file" "$file.gpg"
  • Sign a message: gpg –sign "$file" –output "$file.asc"
  • Verify a signature: gpg –verify "$file.asc"
