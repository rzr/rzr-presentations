* How to ?
  - Requirements:
    - Only a computer
    - time to understand what your are doing
      - Don't erode the quality of the WoT
  - install gpg (or GUI: kgpg)

* Trusting keys
  - Create your key pair:
    - gpg --gen-key
  - Show your keyring:
    - gpg --list-keys
  - Give your "public key" to a friend
    - gpg --fingerprint
  - Recieve your friend "public key"
    - gpg --recv-keys
    - verify fingerprint and owner identify,
    - NEVER blindly trust without verification
  - Trust your friend's key:
     gpg --sign-key "$KEY"

* Using keys:
  - Encode a file for a friend
    - gpg --encrypt --output "$file.gpg" --recipient "$EMAIL" "$file"
  - Decode a file fron your friend
    - gpg --decrypt --output "$file" "$file.gpg"
  - Sign a message:
    gpg --sign "$file" --output "$file.asc"
  - Verify a signature:
    gpg --verify "$file.asc"

* Make your signing party
  - Setup event (in hackerspaces !)
  - Print copies of your keys fingerprints
  - Swap papers (keys FP + email)
    - Verify claimed identify (showing ids)
      - then signed keys can be exported to WoT
	- you will have to learn how :)
   - Pseudonymat should stay local
